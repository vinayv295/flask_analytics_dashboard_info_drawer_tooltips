# Flask Analytics Dashboard

A web-based analytics dashboard built with Flask for uploading, managing, analyzing, and visualizing datasets.

## Features

- Dashboard with KPI metrics
- Interactive charts and analytics
- Dataset upload and management
- Dataset preview
- Dataset deletion
- Reports section
- Dashboard filters
- Informational tooltips
- Dashboard information drawer
- Responsive web interface
- Flask-based backend
- Database-backed dataset management

## Technology Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Chart.js
- SQLAlchemy
- SQLite / supported database
